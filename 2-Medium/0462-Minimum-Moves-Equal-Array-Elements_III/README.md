### Approach Analysis

To equalise all of the elements with the minimal operations is to set up everything to the middle element but for that we need the list to be sorted. So I sorted the list first and then got the middle element and after checking each element and adding all the need for operations to add or decrease by 1 to make every element equal to the value of the middle element.
